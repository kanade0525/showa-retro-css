導入

CSSを読ませて body に sw を付けるだけです。 書体ファイルは任意で、外すとOS標準の和文書体に落ちてそのまま動きます。 地紋も紙のざらつきもさびも、すべてグラデーションと直に書いたSVGで描いているため、読みに行くファイルはCSSだけです。

ファイルを置いて読ませる

<link rel="stylesheet" href="showa-retro.css">

<body class="sw">
  <button class="sw-btn is-enji">押す</button>
</body>

npm から

npm i showa-retro.css

import 'showa-retro.css';         // 全部入り
import 'showa-retro.css/min';     // 圧縮版 60KB / gzip 12.5KB

必要なところだけ読む

src/ に14ファイルへ分けてあります。01-base.css だけ必須で、あとは使うものを足してください。よく使う一式だけなら 23.8KB（gzip 6.0KB）、baseと文字組だけなら 7.9KB（gzip 2.7KB）です。

@import "showa-retro.css/src/01-base.css";   /* 必須 */
@import "showa-retro.css/src/02-moji.css";
@import "showa-retro.css/src/04-kanban.css";

<!-- 付属の晩秋レトロミン -->
<link rel="stylesheet" href="showa-retro-fonts.css">

手元の書体に差し替える

各スタックの先頭に昭和書体の名前を並べてあります。端末に入れるか @font-face を書けば、そちらが優先されます。付属しないのは「商用利用可」と「webフォントとして再配布可」が別の許可だからです。

:root {
  --sw-mincho:   "晩秋レトロミン", serif;
  --sw-jimaku:   "しねきゃぷしょん", sans-serif;
  --sw-tegaki:   "たぬき油性マジック", sans-serif;
  --sw-gothic:   "かんじゅくゴシック", sans-serif;
}

色

色は三層に分かれます。紙と墨と刷り色の六色は昼夜で入れ替わり、物体色（--sw-o-*）は昼夜で変わりません。ホーロー看板や盤面は実物なので、夜になっても色が変わらないからです。ここを混ぜると夜間モードで地色だけが反転して文字が読めなくなります。 刷り色は一枚で多くて三色までを目安に。昭和の印刷は版が少ないので、色数を少なくするほど"らしく"なります。

刷りの表情

レトロ印刷の本質は均一にならないことです。1色ずつ重ね刷りするためランダムに版がずれ、ベタ面にムラが出て、インクがかすれます。 旧版にあった「網点」はやめました。網点は色の深さに応じて点の大きさが変わる仕組みで、同じ間・同じ大きさの点は網点ではありません。点の地紋が要るなら .sw-ji-amiten を使ってください。
